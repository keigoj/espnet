# プロジェクト概要
- 本リポジトリは、ESPnetをベースとした音声認識（ASR）の研究用コードです。
- 離散音声トークンを用いた障害者音声認識の研究のために使います。

# 開発方針
- 既存のESPnetの実装規則に従うこと。
- 必要最小限のコード変更を行うこと。
- 指示されていない実験条件やハイパーパラメータを変更しないこと。
- 既存の実装との互換性を維持すること。

# テスト
- コード変更後は関連するテストを実行すること。
- テンソルの形状やデバイスの整合性を確認すること。
- テストできなかった場合は、その理由を報告すること。

# 作業報告
- 変更したファイルと内容を簡潔に説明すること。
- テスト結果を報告すること。
- 回答は原則として日本語で行うこと。
